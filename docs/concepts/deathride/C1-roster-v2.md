# C1 Roster v2 — design first, 2026-10-01

Scope: content and deterministic core on `deathride/content`. No renderer or art changes. Read Phase 2 in full, Phase 1, G1, W2–W7 and the standalone README. Registry references (read only): game-production `_laws.md`, `tier-band-peer-outlier-linting`, `cost-curve-object-audit`, `data-driven-type-objects-over-subclass-growth`, `canon-as-single-source-of-thresholds`, and the encounter/economy families. CSV remains the project's explicit number authority.

Ten original classes retain the five existing IDs/order for save compatibility. Rookie: Needle, Line, Trail. Club: Bastion, Comet, Flint (compact acceleration/ram specialist). Elite: Quill (light technical racer), Vandal (balanced interceptor), Kestrel (long sprint specialist), Bulwark (heavy endurance chassis). Elite is a broader capability budget rather than a universal speed multiplier: grip, speed, mass, armor and mounts still trade against each other. Approved feel presets remain unchanged.

`cars.csv` owns tier and ammunition capacity multiplier; tier and stat-value tables derive purchase prices. Per-car CSV owns primary stats; `car-shapes.csv` owns physical length/width, retaining the current maximum capsule envelope so existing tracks remain valid. The five added rows reuse procedural shape parameters solely as fallback; no rendering work or new art is included. New IDs and dimensions form the handoff to the art stream. Ammo is consumed by the shared Combat capacity calculation, mounts retain their actual heavy-weapon consumer. Turbo arrives with its mechanic in C3 rather than being an inert field here.

Prices are a rising tier base plus a transparent weighted primary-stat budget in credits, owned by roster pricing data. The audit reports each contribution and distinguishes intended price from measured race strength. Peer comparisons exclude the subject, use a minimum peer population, and report warnings rather than calling a paper score balance. Career purchase/ownership is C3; all ten cars are immediately reachable through existing practice selection, while career unlocks are explicit. Existing rival personalities retain their original chassis until C4.

Validation before commit: content assertions for ten unique identities, complete mappings/shapes/unlocks, price curve, peer lint and live ammo consumer; migration of actual five-car version 1/2 saves; homogeneous six-car course matrix across the five authored course types with the same skill for every class; paired seeded replay; current allocation gates; full `:core:test :link:test :app:assembleDebug`. Require more than one fastest class across course types, publish all results including weak classes. This is a stock movement comparison, not a combat-balance or human-fun verdict. C3 adds the 2,000-race combat scenarios.
