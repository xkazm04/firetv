### LG-28 · Pause & coach repeats the fix the moment just taught, and calls it optional — build (new)
- **Evidence:** the moment stopped the scene with **"ONE THING TO FIX"** and *"Try: Where did you see the rover last time?"* (`shots/tv-moment.png`). Three turns later, *Pause & coach* on the same reply gave the same sentence as an option: *"Your question was clear, and Pip understood it and answered. For a past-time question, you could also say 'Where did you see the rover last time?'"* (`transcript.md`; `shots/tv-recap.png`). Builder's reading: *"The note repeats the moment's fix, so the learner meets the same correction twice, and 'also say' makes it sound optional."* Run 3 did the same (*"A smoother option is 'Where did you see the rover last time?'"*).
- **Root cause, verified in the code:** **the coach does not know the moment happened.** The coach call sends `context(c, false)` and the last reply (`conversation.ts:325-326`). `context()` carries the scene, step, preferences, recent evidence, skills and the last 18 turns, but not `c.moments` (`conversation.ts:83-90`). The moment that taught the fix is not in the coach's input, and the coach task asks for "one useful alternative" (`conversation.ts:325`). This is the same gap behind LG-24 (a taught error not followed up, `context()` omits this scene's moments), seen from the coach's side.
- **Cost/value:** XS. Pass this scene's moments into the coach call. When the coached reply already has a moment, either coach a different change or confirm the moment's fix in the coach's own words, never as optional. This shares LG-24's change, moments in `context()`, so build both together. Value: one correction, said once and said as a correction. A child who is told *"one thing to fix"* and then *"you could also say"* learns that the fix did not matter.
- **Hypothesis left:** that the moments in the input are enough. A haiku coach may still restate the fix. Re-run E5 after the change.
- **Guardrail:** the coach's `before` must stay an exact substring of the reply (`conversation.ts:343`), and the moment's `said` must stay the learner's exact words (`conversation.ts:107`).
- **Ceiling:** the TV recap shows **one** comparison, and when a scene has coaching, the coaching wins over the moment (`lib/english/view.ts:459-462`). Once the two differ, the recap shows the coaching and the moment is only a count (*"1 moment to keep"*). Which one the recap should keep is a question for MH-3 (`docs/LINGA-COMPETITIVE-SCOPE.md` §2), not settled here.

## 3. Methodology lessons

- **Schema miss, again: no `findings.json` and no product commit.** The same miss as run 1 (`2026-10-09-linga-e-run.md` §3). This run's one product gap, LG-28, exists only in a transcript's prose, so the ledger cannot count it or ask a recertify about it.
- **A harness that waits on the wrong condition makes a failure that looks like the product's.** The Maths check waited for `.linga-tv` to vanish, which was already true on the landing, and asserted before the 560 ms zoom ended. The SUMMARY held the cause as *undecided*, and that held up. It did not file a product defect, and run 3's poll answered the question. **Lesson:** a harness waits on the session state the step changes, never on the absence of an element.
- **The builder's reading carried this run's only new product gap.** No assertion compares the coach's note with the moment, because the harness records both but judges neither. A scripted learner with a reader is the right instrument for L2 flow. Recurring readings need a judge pass before they become builds, which is why LG-28 cites two runs.
- **Moments are not asserted** (SUMMARY, *Notes*). Whether one fired is read from the session after the run. Run 3's `results.json` now records `moments[]` with `fired`, which closes this for later runs.
