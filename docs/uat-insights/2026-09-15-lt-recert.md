## 3. Methodology lessons

- **This run is a recertify with its own run id, against the skill's rule.** The skill says recertify has no run id: it re-runs only the affected Character × journey and writes resolutions back into the originating run, with new findings in a `## New findings` section. This run instead re-ran J2–J5 for all ten Characters as a fresh run and produced 74 new open rows, most of them on paths a45cbfae never touched. The parent's `recertify.md` did carry the resolutions correctly. **Proposal:** the ledger-driven `--recertify` (each judge answers its pair's open rows, stamped into the owning run) is the shape to keep; a wide re-run is a new run and should be called one.
- **Schema miss: the second re-certification's resolutions live in prose.** `recertify.md` reports that bc71cb98 raised topic fit to 92% and fixed beginner moments. The rows those results close (11 generic-topic rows, `LT-tomas-9-J3-2`, `LT-martin-45-J3-5`, `LT-tomas-9-J4-3`) are still `open` in this run's `findings.json`, so the ledger counts them. Section 1 reconstructs them. Under the carry-forward rule they would have been `fixed` rows with ceilings.
- **The confound was named, and it was older than this run.** `recertify.md` blames the J2 fixture (level only) for the generic topics. The same fixture produced the parent's J2, so the 52% "before" figure was a no-goal number as well (`2026-09-15-lt.md` §3).
- **The "New findings for the next drain" section worked.** Both items `recertify.md` listed (word-labelled Czech moments; Martin's below-band pitch) arrived here with a door into the backlog: closed-on-main e4bfcfe9, and LG-17.
- **Rubric targets and personal criteria disagree, and the run kept both.** Klára's own spacing criterion passes while the rubric's density target fails (`SUMMARY.md`). That disagreement is the evidence that LG-23 is a segmentation question.
- **The judge's 900-character cut again** (`LT-martin-45-J2-3`, `LT-viktor-67-J2-3`); see LG-3.
