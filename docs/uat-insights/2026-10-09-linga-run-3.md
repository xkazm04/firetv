## 3. Methodology lessons

- **The env contract needs every `CLAUDE_*` variable unset, not just the API key.** The builder's first server inherited the host session's `CLAUDE_CODE_*` variables and was restarted before any request. `uat/env.md` lists the variables to unset for the Essay L2 recipe (`uat/env.md:73`). Its Linga L2 section is still "not scaffolded" (`uat/env.md:56`), so the three Linga runs each wrote their own contract. **Proposal (overlay, not applied):** scaffold the Linga L2 section from the three runs' setups (`tools/linga-ui-test.cjs`, port 3217, `--webpack`, the same unset list), with the same check before the first request.
- **A bare-call baseline separated start-up from model time,** and that changed the latency question from "is thinking on?" to "the CLI costs about 6 s before the model starts". Any later latency claim on the claude CLI should carry this baseline beside it. Three calls on one machine, with a shell wrapper in the wall, make it a reading, not a measurement.
- **A trace that ends at "undecidable" is still useful when it is read against the inputs.** R3 listed every drop condition but did not set them against the scene's allowed skills. Doing that turned "a silent drop?" into "probably no observation, and correctly so" (§2, LG-16). **Lesson:** an evidence trace starts from what the turn was allowed to credit.
- **Schema miss, a third time: no `findings.json`.** Run 3 is the first of the three to write `results.json`, and it records `moments` and `entrances` but no product finding. LG-28's two runs and LG-27's three are visible only to a drain that reads the transcripts.
- **The harness's summary statistic mixed carried-over values into its n**, with no effect here. A harness figure that the run quotes should count only real calls.
