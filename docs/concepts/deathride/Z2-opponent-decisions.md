# Z2 — local decisions, shared attack leases

2026-10-04. Implements Z0 after Z1 commit `a053c36`. Move the six proposed tables into core, extend persona data with explicit corner patience/blocking, and add one numeric control table. Driving modes remain DRIVE/OVERTAKE/RECOVER. The strategy layer chooses targets and ordinary input requests; no physics, speed, grip, damage or promotion-rule cheat is introduced.

Perception runs at the existing skill cadence. Snapshot visible cars inside a car-length range with road/solid line of sight; only visible facts enter target scoring. Public ranks identify the leader duo but do not reveal coordinates. Plans depend on skill, field/rival/boss role, own race progress and position. Seed-rotated hunter eligibility excludes human/declared lead slots; Rookie has none, Club one, Pro two and Champion three. A hunter's live target must remain in positions one/two. Dwell plus score margin stabilizes valid choices; visibility loss, death/finish and recovery release them.

The existing combat `lastTarget` array is the claim authority, with simulation-time expiry and post-hit recovery. Guns, deliberate contact, blocking and offensive abilities share its per-target cap. An already launched projectile, armed mine or committed ability completes normally; accidental physical contact is not erased. Report intentional claim concurrency separately from these residual physical effects. Defensive abilities and clear-road mobility retain their local rules.

Boss HP scales the existing `Car.maxHp` before Combat reset. Repeated reset must not compound it; applying a new chassis clears the previous multiplier. Rival economy receives health divided by that explicit boss multiplier, preserving its historical 0–100 condition input. This is a conversion at settlement, not another HP pool. Boss health is independent of selected difficulty. The visible player target's effective installed stats, same-tier baseline, class identity weaknesses and current damage select a data tactic. Damage knowledge is never read for an unseen car.

Fixed-size primitive arrays retain decisions and cumulative observations. A trace row includes tick, agent, mode, role, phase, public position, visible/candidate masks, target, reason, commitment, weakness and score margin. Export happens outside World.step and states any ring truncation. Independent observers check actual damage and target claims. There is no hunt HUD, new controller action, narration or art.

Tests must show meaningful archetype/persona actions, all four phases, symmetric leader selection, protected starts, visibility/occlusion, commitment, leases/recovery, shared ability slots, installed-stat/damage weakness changes, boss HP reset/settlement, replay, active-step zero allocation and existing save/retry gates. The Z1 solo reference driver can explicitly disable the new strategy for stable course measurement; ordinary play always enables it. Numerical balance and device claims remain for Z3/Z4.

## Implementation and observed checks

The six proposed tables moved to core resources; `ai-control-rules.csv` supplies steering and weakness thresholds. The existing three-mode driving FSM remains. Ten controlled tests cover every chassis/persona, every signature's positive/cooldown decision, all four plan phases and skill budgets, symmetric leader targeting, walls/range, shared weapon/ability leases, hit recovery/expiry/finish, target hysteresis, seven weakness mappings, all five boss health multipliers and repeated reset. The active Champion test makes more than 1,000 decisions during 6,000 measured steps with zero allocated bytes, explicitly requiring hunt and boss-weakness decisions inside the measured interval; paired replays have identical hashes. Existing migration and career retry tests remain in the release gate.

Attack slots bound current AI commitments, not the number of historical projectiles physically travelling through space. A hit releases the source's claim and starts recovery; already committed shots/areas keep their ordinary collision and hit-dedup rules. The trace is a 1,024-row ring, so exported per-event trace files are explicitly the last 1,024 decisions, while damage, claim maximum, leader-change and hunt-decision counters cover the whole observed run. Headless campaign telemetry ends at the lead's finish/wreck/watchdog, and `unresolvedAtLeadExit` therefore includes normally racing peers.

The initial regression run found two old fixtures: the skill-switch test used cars off the road and several decisions in one tick; the signature fixture needed the first decision admitted by the new cadence. The skill fixture now uses road positions and explicit plan resets; the cadence admits the first use. New-test iterations exposed an intentionally held alternative claim, an unfunded late-campaign health fixture and a floating-point lap-boundary endpoint; the fixtures now expire the commitment, explicitly fund their diagnostic rivals and cross beyond the gate. Failure logs remain under `deathride/evidence/ai/z2`. The first broad run was stopped after its known failures to compile these fixes; it is not counted as a pass.

The first complete release run passed 176 of 177 core tests. The old elite-mine regression required the original seed to enter RECOVER; the new behavior avoided that jam. Its test now runs both controls: legacy AI must still encounter and recover from the original jam, and both legacy/new behavior must resolve all six entrants within the unchanged 300-second synthetic horizon. Both controls passed. This preserves recovery coverage while accepting a clean run that never needed recovery.

Final gate: 177 core, 8 link and 37 game tests pass, as do `:app:assembleDebug`, desktop packaging and all six browser suites. Exact commands and counts are in `deathride/evidence/ai/z2/release-final/passed.json`. No balance acceptance is inferred from these correctness tests.
