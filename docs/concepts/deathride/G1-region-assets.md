# G1 — Region candidates, never automatic approval

2026-10-04. Design first; follows [G0](G0-region-bible.md). Only art tooling, candidate assets, review pages and evidence change. Production assets, course data, runtime, owner decisions and the Stick stay untouched.

The catalog is derived from G0's five tables; it stores division association, palettes, local-metre footprint/effect/height proposals, reuse references and fallback. It is an art manifest, not G2's `region.csv`. Generate through unchanged `gen.py` with its exact fusion choice check, prompt provenance, durable stop latch, immutable IDs and three-attempt ceiling. Add a prefix-scoped 130-reservation session envelope to the existing 850 global cap. Paid scheduling is sequential so a detected quota stop cannot start further calls. Proofs per region and asset family are inspected and hash-bound before sibling generation; proof release is technical screening, not an owner pick.

Props export at up to 128 px, retaining unchanged full-resolution sources in review to avoid hiding the owner's previous derivative-quality concern. Backdrop square exports are 512²; horizon exports preserve the full 2:1 source in a 1024×512 panel, never stretch. Weather uses six equal source cells with shared scale/pivot and the existing animation gates, exported at 64². Empty/cropped/key-contaminated/duplicate frames fail. Pixel thresholds and fusion style bytes remain unchanged. Two local models observe exact source and weather export sheets; custom regional questions also check face-free content and overhead prop projection, which the legacy general grader marks not applicable for non-cars. Low confidence/disagreement stays visible; no observation is human calibration.

Recolour existing technically selected worn asphalt, dirt, gravel and alpine frost by a deterministic luminance-preserving material tint, retaining source/export hashes and recipe. Check every final 256² tile against the existing seam/repetition gates and inspect real 2×2 repeats. The only planned new ground sources are fine salt crust and cold clinker; use the existing bounded eight-pixel edge wrap remedy only when necessary and retain the failing original. Do not disguise a repeated motif by tinting it. Failed items have explicit procedural/existing-material fallback.

Pack technical candidates in a separate `art/regions/candidate-pack` folder outside packaged `assets/`. One 1024² page per region holds that region's eligible props/weather. Keep existing approved props as exact atlas aliases. Record actual source/export/page hashes, placements, gutters, frame timings, fallback and replacement slots in `atlas-plan.json`; no asset has a new owner approval or runtime activation. G0's conditional 30.25 MiB plan replaces the unused track-edge atlas and old backdrop allocation, preserving car reserve and one active region. A dedicated validator checks actual byte accounting and fail-closed activation prerequisites; `validate_bundle` checks both unchanged production bundles at commit time.

Five offline owner pages reuse the audio report's CSS and interaction/export format, with no preselected picks. They show every requested item, including gaps, technical defects, source and native views, palette/plot and per-region budgets. Browser checks cover desktop/mobile, file links, unloaded images, blank initial selections, persistence, Markdown escaping and Copy Markdown. Tests cover the guard chronology, no owner approval, untouched runtime/track bytes, atlas byte/overlap/hash integrity and rejection/fallback invariants.
