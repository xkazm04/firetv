## 3. Methodology lessons

- **(a) The ledger folds Essay and Math rows into "Open LT findings - Linga".** `uat/driver/ledger.cjs` reads every `findings.json` in `uat/runs/` and writes one table headed for Linga LT, so a recertify against Essay rows (EM-B4 and after) would be asked in the Linga ledger's words. Not applied (W5/W6 are docs only); proposed: a module key on the ledger.
- **(b) `uat/driver/product.cjs` counts a one-sided path as changed**, so every Essay and Math row reads *aged* at an unchanged `desk/src`. This drain saw it as a false alarm: `git diff --stat 12592a71 HEAD -- desk/ tools/` printed nothing, so no row is aged. Not applied.
- **(c) `tools/uat-verdict-test.cjs` throws ENOTDIR on `uat/runs/OPEN.md`.** The file is written by `linga-text.cjs --status` without `--runs`, which this drain never ran; it is a latent red in the rule suite. Not applied.
- **(d) `rubric.md` has no grounding denominator for Essay or Math.** W5 fixed ES-READ 8 and ES-REVISE 7 in this run's SUMMARY.md (and MB-READ 5, MB-MARK 6, MB-HINT 8, MB-EXPLAIN 8, MB-SET 7, MB-WORKED 5, MB-PICK 3 in the Math SUMMARY.md). They are the orchestrator's, not the rubric's: a later run that recounts them may get other denominators. Not applied.
- **(e) `rubric.md`'s *Finding schema* line names `cert_level` LT only.** These runs carry `cert_level: "L1"`; the schema line should list L1, L2, LT and LC. Not applied.
- **A *covered-elsewhere* class can be reopened by convergence.** The W-run's accounting #2 (the ghostwriting check is a substring test) and #5 (a note contradicting its code verdict) were covered-elsewhere, waiting for the owner's reading. Three independent Characters now raise #2 (EM-B7) and three raise the faulty-verdict form of #5 (EM-B6). A drain that reads the prior run's *covered-elsewhere* rows should re-count them when a later run converges on them, rather than inherit the class.
- **A ruling made after the walk can overrule a row's own acceptance.** `L1-daniel-15-EM3-7` and `L1-kristyna-17-EM3-5` propose reading a short unpunctuated first line as the title with the shelf's own `titleOf` rule. R3 removes that inference because it breached the curtain (`L1-helena-46-EM5-1`). The drain keeps the rows' cause and drops their proposed acceptance (EM-B17). The walkers were blind to each other's rows, so the conflict only shows in a drain.
- **Severity was derived, not labelled.** The orchestrator raised two walker labels by impact rank (`L1-kristyna-17-EM1-4` and `L1-kristyna-17-EM3-2`, major to blocker). The drain uses the findings.json severity, not the pair files'.
- **Eight rows are `uncertain`** (model output decides): their root causes stay hypotheses in the backlog, each with its L2 question in the row's `l2_priority`. EM3 and EM5 have never been reached at L2 (`uat/env.md`), so the whole-piece and Workroom entries (EM-B26, EM-B15, EM-B10, EM-B28, EM-B33, EM-B29) have an L1 reading only; verdict agreement, 0.69 for Eliška and 1/8 for Kristýna, is a code-only proxy over simulated observations.
- **The reconcile gate was cheap and clean.** `git diff --stat 12592a71 HEAD -- desk/ tools/` printed nothing and neither insight doc existed on main (the last commit under `docs/uat-insights/` is 12592a71, the Linga E drain), so nothing was closed-on-main and nothing was re-verified.
