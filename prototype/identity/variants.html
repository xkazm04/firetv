1 · Night Desk

The room is the interface: one lamp, one page, a hint written beside it. Escapes the settings feel by making the page a physical object with a shadow and a tilt, and the hint a different voice — a serif — from the chrome.
Type
Fraunces (hint, learner) · IBM Plex Sans (chrome) · Plex Mono (timer, item numbers)
Palette
#0E1512 night · #F5F1E6 paper · #E8B86D lamp · #9AA697 moss
Techniques
Layered radial gradients as light; SVG turbulence as grain; a rotated surface with a real shadow; a hand-drawn SVG arrow as the only ornament.

2 · Arena

A game menu's register: a session meter that fills, a quest card, the focused control breathing. Reads as play, not admin — the risk is that a tutor's hint feels like a power-up.
Type
Sora (display, buttons) · Nunito (body)
Palette
#10163A cobalt night · #FF6B5C coral · #7FE3FF ice · #FFB25C ember
Techniques
Two-colour atmosphere by radial gradients; a slow orbit ring with a glowing satellite; glassy panels; a breathing focus ring via animated box-shadow.

3 · On Air

The telestrator's lineage — broadcast graphics. Lower-third for the problem, an on-air caption for the hint, a diagonal band, condensed caps. Unmistakably a production, and the timer becomes a clock on screen.
Type
Barlow Condensed (display) · Barlow (body)
Palette
#14161A charcoal · #E23D28 signal red · #FFB4A8 tint · white
Techniques
clip-path band with a scanline overlay; a faint 120 px production grid; backdrop-filter glass; skewed focus with an offset hard shadow.

4 · Soft Studio

The friendly-app register, and deliberately light on a TV. Layered pastel forms, deep rounded surfaces, the hint as a tutor's speech bubble. The most approachable; check it against a bright room and a dim one.
Type
Plus Jakarta Sans throughout, weight doing the hierarchy
Palette
#EEF1F6 cloud · #1C2333 ink · #4C7BFF blue · #F07A3C apricot · pastel forms
Techniques
Big blurred circles as depth; a single dark surface (the bubble) carrying the voice; an abstract tutor mark built from two CSS shapes; soft shadow scale on focus.

5 · Blueprint

The drafting table — the subject's own instruments. Graph paper, a title plate, a callout on a leader line, coordinates for the problem's form. Maths-native, precise; the least warm.
Type
Manrope (body) · JetBrains Mono (figures, labels, buttons)
Palette
#0E1626 navy · #7FD1E8 cyan ink · #F2C14E marker yellow · #7A8DA6 pencil
Techniques
Two-scale grid from four linear gradients; a vignette to focus the eye; an SVG leader line with a dot; a title-plate label cut into the border.
