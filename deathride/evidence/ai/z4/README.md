# Z4 owner review and Stick check

- [Owner review](../../../ai/design/index.html): static offline page, generated by `tools/ai-owner-review.py`; [source hashes and decision IDs](../../../ai/design/manifest.json).
- [Required release gate](release/passed.json): 177 core, 8 link, 37 game tests; APK, desktop packaging and six existing runtime browser suites. Gradle reused up-to-date runtime outputs because Z4 changes no game code/data.
- [Final offline page checks](review-final/result.json): source/asset checks, all content counts, every decision/note, persistence, safe Markdown export, clipboard fallback, denied/corrupt storage and desktop/mobile themes. Screenshots use disposable test contexts; test selections are not owner choices.
- [Stick summary](stick/summary.json), [inventory](stick/README.md), [lossless telemetry archive hashes](stick/telemetry-archives.json). The original interrupted run is retained separately from the completed `campaign-resumed` run. The isolated app was stopped after the check; TV/tracks identities were unchanged.

`review-first/result.json` retains the initial stopped browser harness: offscreen lazy images were not explicitly loaded before decode. `review-second` and `release/review-browser` passed after correcting the harness. `review-final` rechecks the final page after telemetry compression and link updates. This was a check-harness correction, not a runtime change.

The page reports Z3's failed balance findings as well as passes; no new simulation samples or balance tuning are introduced. Boss promotion still requires first place. No visible hunt cue, generation spend or push.

Rebuild locally from the Death Ride directory:

```text
python tools/ai-stick-summary.py
python tools/ai-owner-review.py
node tools/ai-review-check.mjs evidence/ai/z4/review-final
python tools/ai-wave-check.py evidence/ai/z4/release
```

Use a fresh output directory/tag for new evidence. Device discovery helper: `python tools/ai-device-scan.py <active-LAN-/24> <new-scan.json>`. Inspect foreground availability before a new device run; the installer/runner wait up to sixty seconds for another Death Ride app, then record pending rather than displacing it. Fresh results retain their raw JSON until archived; `ai-stick-summary.py` accepts JSON or its exact gzip equivalent.
