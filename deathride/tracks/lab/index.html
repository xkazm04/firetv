Track Lab

Shape a draft, inspect the linter, then watch six AI cars use it. Geometry and races run in the actual game core.

Edits live in memory. Export downloads a draft CSV bundle. The tool has no endpoint that writes existing course data. One quick race is a probe; the atlas provides the multi-seed evidence.

Keep that process running, then press Connect. This file page connects only to http://127.0.0.1:8794. You can also use the local page printed by the service. No installation or device is involved.

R2 design primitive composer

Anchor rows use x and y in longest-car lengths, radius in longest-car lengths and full width in widest-car widths. The compiler creates tangent straights and corner sequences, then bakes the game spline. Edit anchors or expanded primitives; an open sequence reports its closure error.

Primitives: start (x, y, heading); straight (length); corner/sweeper/kink (angle, radius); hairpin/double-apex (total angle, radius, middle straight); chicane (first angle, radius, gap); esses (first angle, radius, gaps). junction (crossing x, y, warning distance) explicitly permits an at-grade crossing. A split row (main start fraction, end fraction) followed by a complete alternate recipe and a final rejoin row creates a second passage. Its ends must meet with matching tangents and widths; the grid moves clear. Bridges are unsupported.

    Declared at-grade junctions
    Two absolute lap fractions identify intersecting straight passages. Cars collide at road level; passage-aware progress prevents switching arms to skip a lap. Bridges are not supported.
    

    Optional route intervals
    The split block compiles a complete alternative centreline. Only its declared passage is driven and rendered. Both passages share canonical checkpoint progress. Branch node CSVs are retained in the draft and ZIP; edit the recipe to change their geometry.
